Política de cookies

Última actualización: [FECHA DE PUBLICACIÓN]

Revisión necesaria antes de publicar. Confirma el inventario real con herramientas de inspección de cookies y red en producción, y completa responsable, proveedores, finalidades, duración y base jurídica según la configuración final.

1. Qué son las cookies y tecnologías similares

Las cookies son pequeños datos que un sitio puede almacenar en el navegador. Esta política también describe el almacenamiento local y las solicitudes a recursos externos que pueden revelar datos técnicos de conexión.

2. Tecnologías utilizadas actualmente por el código

  • Sesión de servidor: la cookie `modeos.sid` mantiene la sesión necesaria para Discord y la zona DEV. Está configurada como HTTP-only, con duración máxima de ocho horas y Secure en producción.
  • Elección de privacidad: `localStorage` guarda `modeos-cookie-consent`, incluyendo categorías elegidas, versión y fecha/hora de decisión. Se usa para recordar la elección del banner.
  • Analítica: esta versión no configura un proveedor de analítica ni publicidad. Las categorías opcionales se mantienen apagadas hasta que el usuario las autorice y solo se activarán si se añade un script registrado para esa categoría.
  • Personalización: no hay actualmente un proveedor opcional de personalización configurado. La categoría se ofrece como control para integraciones futuras.

Las tecnologías esenciales se usan para prestar una función solicitada, conservar la elección o proteger la sesión. Las opcionales requieren una decisión afirmativa cuando la ley lo exija.

3. Recursos externos de interfaz

La versión actual de `index.html` carga Tailwind CSS desde `cdn.tailwindcss.com` como script de interfaz y obtiene fuentes desde Google Fonts e iconos desde cdnjs/Font Awesome. Esas solicitudes se realizan al cargar la página, independientemente de las categorías opcionales, para representar la interfaz existente. Los proveedores pueden recibir datos técnicos como dirección IP, agente de usuario y URL solicitada. El código de la web no usa esos recursos como herramientas de analítica, pero el responsable debe revisar las condiciones de cada proveedor y sus transferencias.

Para reducir dependencias de terceros y solicitudes antes de la elección, compila y aloja localmente Tailwind, las fuentes y los iconos. No declares esos recursos como “cookies esenciales” sin verificar que esa clasificación sea correcta.

4. Categorías y opciones

  • Esenciales: necesarias para la sesión, seguridad y recuerdo de la elección. Permanecen activas.
  • Analítica y rendimiento: desactivada por defecto. No se descarga ningún script registrado en esta categoría hasta una autorización afirmativa.
  • Personalización y preferencias: desactivada por defecto. No se descarga ningún script registrado en esta categoría hasta una autorización afirmativa.

5. Cómo cambiar o retirar el consentimiento

Usa “Configurar cookies” en el pie de la web para modificar la elección en cualquier momento. La nueva selección se guarda con una fecha/hora y se comunica a las integraciones mediante un evento. Los scripts que ya se hayan ejecutado pueden requerir instrucciones propias del proveedor para detener procesos y borrar identificadores; el responsable debe incorporar esa lógica antes de añadir cualquier proveedor opcional.

6. Cómo eliminar datos almacenados

Puedes borrar los datos del sitio desde la configuración del navegador. Esto elimina la elección guardada y el banner volverá a aparecer. La eliminación de la cookie de sesión puede cerrar la sesión del sitio. Borrar almacenamiento del navegador no elimina los datos que el servidor ya haya guardado en Neon; para ello contacta con [EMAIL DE PRIVACIDAD].
